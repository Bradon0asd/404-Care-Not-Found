# 介面語言

介面使用本地中／印尼文語系表，不會呼叫翻譯 API，也不會下載或執行翻譯模型。

- `id.ts`：中文原文對應印尼文的固定文案。譯文供展示使用，尚未經印尼語母語者審校。
- `index.ts`：註冊 Vue `$t()`；讀取 `onboarding.language`，同步 HTML 語言與頁面標題。
- 語言可從登入建檔頁或 Tab05 變更，使用 `care-ui-language` 保存於 localStorage；未選擇時預設中文。
- 使用 `$t('中文原文')`；含變數的文案使用 `$t('簡單概述 {name} 的日常紀錄', { name })`。
- 日記日期依語言顯示民國日期或印尼文日期。
- 標記為 `demo` 的便利貼與聊天室示範內容可翻譯；使用者新輸入的內容保持原樣。
- 新增 UI 文案時，須同步加入 `id.ts`。不要將輸入框的 v-model 值送入 `$t()`。

只有語言偏好會保存；日記、對話及其他前端示範資料仍只存在記憶體中。
